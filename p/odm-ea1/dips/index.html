DIP switches and troubleshooting

Mostly for troubleshooting. To adjust brightness with the device open and off, power the module from micro-USB: it shows its start screen (serial number, www.xrd.lv/p/odm-ea1, "(no incoming data)", firmware version) while you turn the trim pot. No DIP switch is needed (firmware v1.0.4 and later). This page describes firmware v1.0.7, the one modules ship with now; older versions are noted where they differ.

In normal use, DIP 4, 5 and 7 are off (towards the middle of the module): a test mode left on interferes with normal operation. Leave DIP 6 as it came: it is set for the panel fitted (on most white modules it is on).

Where they are

Under the OLED panel. Press the plastic clip (on the long edge, near the USB socket) towards the board and, holding it, slide the panel up. The install guide has photos. The module can be powered on its own from a micro-USB cable.

What each switch does

DIP 1Inverted display
DIP 2, 3Brightness: both off = set by the trim pot; only DIP 2 on = lowest, only DIP 3 on = medium, both on = highest (the pot is ignored)
DIP 4Debug screen: "DBG", the firmware version, the state of the input pins, the trim pot and brightness readings
DIP 5Panel test: a sliding unlit vertical bar (inverted with DIP 1)
DIP 6v1.0.6 and later: the panel's column offset, set when the module is built for the panel fitted (on for most white modules). Leave it as it came: in the wrong position the picture is shifted 4 pixel columns. Before v1.0.6: test text.
DIP 7A sample Analog Keys screen (v1.0.2 and later; v1.0.1: debug output over USB serial). Makes the screen look stuck if left on.

Nothing on the screen after installing

  1. Look over all solder joints: each should have a clean fillet, and no solder bridging neighbouring pins.
  2. Check the panel: with DIP 4, 5 and 7 off (DIP 6 as it came), power the module from a known-good 5 V micro-USB supply. It should show its start screen with the serial number and a web address (before v1.0.4: switch DIP 6 on for test text). If not, the flat cable from the panel to the board has probably come loose: reseat it. If that doesn't help, the panel or board is faulty.
  3. If the panel works: switch DIP 4 on and all others off. It shows "DBG", "fw" with the version, and graphics that follow the input pins. Disconnect USB, then film the DBG screen while you power on the Elektron device, and send the video to e-mail: it shows whether an input pin gets no signal from the main board.

With USB power in DIP 4 mode, a multimeter in diode mode can also check that every signal from the main board reaches the module. If nothing helps, send the module in and we try to fix it.

Known issues

  • Picture shifted sideways by a few pixels: DIP 6 is not in the position the module came with (firmware v1.0.6 and later). Flip it.
  • Vertical halo stripes, bottom-row leakage: fixed in firmware v1.0.5 (revC boards on). Write to e-mail with a photo of the serial number (left side of the bracket, below the code).
  • Screen protector pushed out: the kit's spacers were used; fit Elektron's original ones.
